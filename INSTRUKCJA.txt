JW STUDY 2.84 — PODMIANA NA GITHUB

1. Rozpakuj ten ZIP.
2. Na GitHub otwórz repozytorium JW-Study-3.1 i gałąź main.
3. Wgraj do GŁÓWNEGO katalogu repozytorium dokładnie te cztery pliki:
   - index.html
   - sw.js
   - WERSJA
   - README.md
4. GitHub ma je zastąpić (Replace/Overwrite), a nie dopisać kopie z numerem.
5. Zatwierdź zmianę przyciskiem Commit changes.
6. Poczekaj, aż Actions / pages-build-deployment pokaże Success.
7. Otwórz:
   https://skarzynski76.github.io/JW-Study-3.1/?v=284

Nazw plików nie trzeba zmieniać — w paczce są już prawidłowe.

Usuń z repozytorium błędne kopie, jeśli nadal występują:
index .html, index 3.html, index 5.html, sw 2.js, sw 3.js, sw 4.js.

Nie usuwaj katalogu lib ani pozostałych plików JavaScript.
Nie czyść danych Safari i nie odinstalowuj aplikacji bez wykonania kopii notatek.
