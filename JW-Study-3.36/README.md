# JW Study 3.36

Aplikacja do notatek i studium.

Wersja 3.36 usuwa zależność importu PDF/DOCX/OCR od zewnętrznych plików bibliotek: są wbudowane w `index.html`. Dodaje wybór zdjęć/zrzutów i wklejanie obrazów ze schowka.

Instrukcja aktualizacji i ograniczenia: `AKTUALIZACJA-3.36.txt`. Wgraj zawartość tego katalogu do dotychczasowego katalogu publikacji, zachowując nazwy.

Licencje bibliotek: `lib/smart-import/`. Opis lokalnej poprawki Tesseract: `lib/smart-import/MODYFIKACJA-3.36.txt`.

Testy: `node testy/regresja.js`.
